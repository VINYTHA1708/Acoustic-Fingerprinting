======================================================================
  Dataset        : MIMII (Zenodo 3384388)
  Machine types  : fan, pump, slider, valve
  Machine IDs    : id_00, id_02, id_04, id_06 (4 per type, 16 total)
  Split          : train=0.70 / profile=0.15 / test=0.15  seed=42

  Primary metric : ROC-AUC (threshold-free)
  Anomaly score  : normalized Euclidean drift on 256-dim L2-normalised embedding
  N test normal  : 2222
  N test abnormal: 3300

5. LITERATURE CONTEXT  (comparability_level = CONTEXT_ONLY)
======================================================================
  PROTOCOL MISMATCH WARNING
  ------------------------------------------------------------------
  The numerical values below are taken directly from the cited papers.
  They are listed for orientation only.  Numerical differences between
  these values and the proposed method's results CANNOT be interpreted
  as head-to-head performance differences because the evaluation
  protocols differ in at least one of the following material respects:

    - Dataset version: literature uses DCASE 2020 Task 2 dev set;
      this work uses MIMII Zenodo 3384388 original release.
    - SNR conditions: DCASE 2020 mixes multiple SNR levels;
      this work uses the 0 dB SNR mix only.
    - Train/test split: DCASE 2020 uses its own fixed split;
      this work uses train=0.70 / profile=0.15 / test=0.15 seed=42.
    - Machine-ID selection: literature machine IDs unconfirmed.
    - Averaging: literature reports average AUC per machine type;
      this work pools all recordings across types.
    - Some literature methods use machine-ID conditioning (ID-aware),
      which is a strictly stronger supervision signal.

  No statistical tests are performed against literature values.
  No better/worse judgement is made about any literature method.
